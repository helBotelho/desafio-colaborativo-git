# Desafio Colaborativo Git - Documentação de Operações

Projeto de calculadora desenvolvido em **linguagem C**! Abaixo estão detalhadas as operações implementadas pela equipe.

## Subtração

Programa em C desenvolvido para realizar a operação de **subtração** entre dois números.

### Como Usar
1. **Compile o programa:**
   ```bash
   gcc calculadora.c -o calculadora
execute o programa:
  ./calculadora 

Escolha uma opcao: 2
Digite o primeiro numero: 10
Digite o segundo numero: 4
Resultado: 10.00 - 4.00 = 6.00

## Divisão

Módulo responsável por calcular a divisão exata entre dois números reais.

### Como Usar
1. **Compile o programa:**
   ```bash
   gcc calculadora.c -o calculadora
execute o programa:
  ./calculadora 

### Exemplo
Escolha uma opcao: 3
Digite o primeiro numero: 10
Digite o segundo numero: 4
Resultado: 10.00 / 4.00 = 2.50

## Multiplicação

Módulo responsável por multiplicar dois valores inteiros informados pelo usuário.

1. **Compile o programa:**
   ```bash
   gcc calculadora.c -o calculadora
execute o programa:
  ./calculadora 

### Como fazer
O programa exibirá a mensagem "Digite o primeiro número:" para você fornecer o primeiro valor inteiro.
Em seguida, pedirá o segundo número com a mensagem "Digite o segundo número:".
O sistema calculará a operação utilizando a variável resultado para exibir a saída final.

### Exemplo
Digite o primeiro numero: 20
Digite o segundo numero: 3
Resultado: 20 x 3 = 60

## Soma
Este programa em C solicita ao usuário dois números inteiros, armazena os valores nas variáveis a e b e realiza
a soma entre eles. O resultado é armazenado na variável soma e exibido na tela.

**O programa utiliza a função scanf() para receber os valores digitados e a função printf() para mostrar o resultado final.**
### Exemplo
Escolha uma opcao: 1
Digite o primeiro numero: 15
Digite o segundo numero: 7
Resultado: 15.00 + 7.00 = 22.00
