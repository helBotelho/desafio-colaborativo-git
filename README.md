#Subtração

Programa em C que subtrai dois números.

Como usar
Compile: gcc calculadora.c -o calculadora
Execute: ./calculadora
Escolha a opção 2
Digite os dois números
Veja o resultado
Exemplo
Escolha uma opcao: 2
Digite o primeiro numero: 10
Digite o segundo numero: 4
Resultado: 10.00 - 4.00 = 6.00
